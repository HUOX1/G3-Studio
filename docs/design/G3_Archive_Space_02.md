## G3 的转译

选择 MUSIC：基准版本中的 COMICS 已接入 spatial_gallery.gd，不能视为占位；MUSIC 没有音乐业务，且本聊天前一版档案实验使用的也是这里。内部 ID 不变，导航提示改为“游戏藏品室（实验）”。

构图采用暖灰展台、两组沿纵深延伸的薄厚档案、向前抽取的大封面，以及右侧无实心面板的文字区。当前主封面明显大于侧档案，详情进一步抬起并转向观察者。不是规则横轴或网格。

场景由 Godot Node3D、Camera3D、MeshInstance3D、SubViewport、CanvasLayer 与原生 Control 构成；archive_stage.tscn 是独立舞台。私有 World3D 隔离相机、光照与环境，不改原空间展厅。运行时动态构造几何与排版，延续 G3 既有模式。

材质包括原创封面适配 Shader、薄层玻璃 Shader 和结构地面 Shader。封面保持完整比例，不裁掉封面边缘；边框和基座有实际厚度，主光产生方向性阴影。玻璃使用透明涂层和有限高光；磨砂以封面纹理的五点小半径采样近似，不做物理多层折射，也不使用屏幕空间全屏模糊。

排版优先已有 games 字体组别；未指定时使用 SystemFont 的微软雅黑／PingFang／Noto CJK 回退，标题采用较高字重，正文和小标签保持稳定。长标题最多三行并提供完整工具提示；索引保留完整标题。小窗口缩放不把普通阅读文字压到布局缩放比例以下。

真实数据来自原 library.games.list 的返回字典，包括 cover、title、platform、source、description、genres、playtime_seconds 和 playable；不创建演示收藏或写库。封面仍遵循工作线程解码、主线程创建纹理的既有流程；缓存最多 32 项，长边最多 1200 像素；代次和路径共同阻止过期结果串图。缺少或损坏封面时使用带游戏名的实体占位；插件缺失不会阻止原页面及档案脚本解析。GIF/APNG 等格式仅在扩展可用时读取静态海报，本实验不播放动态封面。

## 操作

| 输入 | 结果 |
| --- | --- |
| 单击展品 | 选择／聚焦，不启动 |
| 双击当前展品、Space、打开档案 | 进入／切换详情 |
| Esc、返回阵列 | 关闭索引或返回浏览 |
| 滚轮、方向键、上一件／下一件 | 浏览；从详情切换后回到浏览 |
| Enter、详情中的启动按钮 | 通过现有 game.play 路径明确启动 |
| G、玻璃按钮 | 清晰／轻磨砂，保留视角 |
| /、藏品索引 | 搜索名称、英文名、平台和来源；选择结果仅聚焦 |
| 动态按钮 | 本次会话减少动态；不写入全局设置 |

启动过程显示请求状态，阻止重复请求，收到拒绝、离线或后端失败时在本版块显示原因。其他版块仍调用原来的启动方法。键盘导航与减少动态模式即时落位；鼠标空间过渡采用指数趋近，约 167ms 达到 95%，约 256ms 达到 99%，可从当前位置接续，无反弹、无待播放队列。悬停只抬升 0.055 世界单位。没有文字逐字播放、数字滚动、待机漂浮或持续相机晃动。

## 动效与视觉审查

| Before | After | Why |
| --- | --- | --- |
| 旧档案实验的高俯角与小卡片 | 低角度、大主封面、两组后方档案 | 强化藏品中心和遮挡纵深 |
| 中央深色通道与大信息面板 | 连续浅色展台与轻量文字区 | 让封面与信息承担视觉权重 |
| 环境雾使主封面变灰 | 主封面关闭雾混合，远档案单独收敛对比 | 尊重原始封面色彩 |
| 阵列与文字重叠 | 将侧阵列收进右侧信息区以外 | 保持标题、说明和操作的对比度 |
| 焦点输入框消耗 Esc | 索引层提前处理 Esc 并停止向下传递 | 真实键盘测试可关闭索引 |

## 验证与边界

见补丁内 VERIFICATION_验证记录.md 和 reports/ 日志。Godot 4.7.2 Linux 已做脚本解析、场景运行、原生逻辑检查与 OpenGL Compatibility 软件渲染；截图为实际渲染，使用原创诊断封面及临时 Noto CJK 字体验证中文。诊断封面和字体文件不安装到产品；实际使用依赖现有游戏数据、字体设置与 Windows 字体。
