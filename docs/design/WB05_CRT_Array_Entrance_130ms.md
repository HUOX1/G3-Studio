# WB05 CRT / VHS 阵列封面成像入场（当前状态）

## 目标与当前基线

- 首次海报墙构建时，真实封面纹理完成解码并应用后才启动成像；只对当前可见且已加载的封面播放，按网格顺序逐张启动，实际启动间隔 **130ms**，动画彼此重叠。
- 单张封面实际播放 **960ms**。Shader 沿用单卡 HTML 的 **520ms 内部时间轴**，由 `game_section.gd` 将实际时间按 `520 / 960` 映射给封面与光晕 Shader。
- 封面由独立 `crt_proxy` 成像层绘制。动画期间隐藏原始 Button，并保持 wrapper 透明；只有真实封面、亮线和受控光效可见，不显示空卡片底板。
- 动画完成后原子切回正常 Button / 封面层，恢复鼠标输入；后续排序、搜索、滚动和重建不重复播放冷启动成像动画，沿用原有布局与弹簧交互。

## 当前单卡时间轴

| HTML 内部时间 | 实际播放时间（约） | 阶段与动作 |
|---|---:|---|
| 0–70ms | 0–129ms | 预热通电：中心亮线与初始信号出现 |
| 70–190ms | 129–351ms | 显像展开：封面从中心向上下展开，RGB 色偏与扫描纹理逐步显现 |
| 190–290ms | 351–535ms | 信号锁定：封面稳定，磷光与外围辉光建立；VHS Tracking 在本阶段后段开始 |
| 290–430ms | 535–794ms | 空间归位：整个独立成像层向上移动约 10px 并缓出归位；锁定高光同步扫过 |
| 430–520ms | 794–960ms | 余辉收敛：扫描线、色偏、噪点与辉光逐步退去，恢复干净封面 |

> 实际播放时间由 960ms / 520ms 的比例换算，表内为近似值；130ms 是相邻卡片的启动间隔，不是单卡动画时长。

## VHS / CRT 风格层

- **VHS Tracking**：内部时间 214–326ms（实际约 395–602ms）触发一次短暂横向追踪失真，集中在一条移动的水平带内；只扰动封面采样，不移动卡片节点或布局。
- **RGB 分离**：内部时间 70–360ms（实际约 129–665ms）增强红 / 青蓝通道错位，随着信号锁定逐渐收束。
- **扫描线与光栅扫带**：扫描纹理主要出现在内部时间 70–360ms；移动的亮光栅带出现在 120–318ms，增强 CRT 逐行成像的感觉。
- **双层磷光辉光**：封面内缘使用青白近层与品红远层；外围 `crt_halo` 使用加法混合的青 / 粉双层柔光。外围光晕仅在内部时间 190–520ms 工作，避开亮线和封面尚未完整展开的阶段。
- **信号锁定高光**：内部时间 292–382ms（实际约 539–705ms）横向扫过封面，与 290–430ms 的整体上移归位阶段重叠。
- **模拟噪点**：只在成像过程叠加很轻的确定性亮度噪点，并随最终收敛阶段消失；不降低应用帧率。

## 已确认的设计决策与问题结论

- 原始 Button / wrapper 不是最终“容器感”的主要来源。分层诊断曾分别隔离正常渲染、关闭光晕、仅光晕及两层关闭；仅光晕模式仍出现暗色轮廓，说明旧光晕混合方式会形成类似卡槽的暗边。
- 外围光晕改为加法混合并延后到封面完整展开后；之后在不恢复旧暗框的前提下重新加入柔和双层辉光。
- 单卡 HTML 的上移动作必须作用于整个独立成像层，使封面与其子级光效同步移动；不能只改变 Shader 顶点，否则附属效果可能留在原卡槽位置。
- 曾尝试的轻微 Y 轴透视倾斜不够明显，却带来封面边缘锯齿；当前实现不使用该几何倾斜，保留无透视变形的轻微缩放、软化显像边缘及整体上移归位。
- 当前优先级是保留已稳定的无容器、无明显锯齿结构，再增强 VHS / CRT 信号过程；不叠加额外场景装饰、文字或网格背景，以免遮挡真实游戏封面。

## 当前实现文件

- `g3_frontend/scripts/game_section.gd`：独立成像层创建与切换、真实纹理解码门槛、960ms 实际时长、520ms Shader 时间映射、130ms 错峰、上移归位及完成后的交互恢复。
- `g3_frontend/shaders/g3_crt_signal_cover.gdshader`：中心亮线、展开遮罩、RGB 分离、VHS Tracking、扫描线、光栅扫带、内缘磷光、锁定高光及轻微噪点。
- `g3_frontend/shaders/g3_crt_signal_halo.gdshader`：延迟启用的加法混合外围青 / 粉双层辉光。
