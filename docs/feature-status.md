- 用户正在学习 DaVinci Resolve，为游戏和电影制作动态封面 / Hero / LOGO

- 目前 166KB，`_on_backend_response` 是极长的 if-elif 链
- 拆分为 `backend_router` / `movie_controller` / `game_controller` / `system_controller`

### 优先级 3：代码审计收尾与清理

- `monitor_exe` 60 秒没出现仍计入时长（待修）
- 侧边栏主题色渐变（新想法）
