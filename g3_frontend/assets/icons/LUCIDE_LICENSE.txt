Lucide icons — used by G3-Studio game section (WB-04)
=====================================================

The SVG files in this folder (games, movies, lab, music, system, add_circle,
magnifier, sort_name, sort_playtime, sort_recent, game_count) are the official
Lucide "Regular" shapes, bundled locally so the UI never needs a network
request and never depends on the in-app icon lab download button.

Source  : https://github.com/lucide-icons/lucide (lucide-static v1.63.0)
License : ISC
Changes : stroke colour changed to #FFFFFF so the app can tint the icon with
          the current theme foreground; width/height attributes kept at 24.
